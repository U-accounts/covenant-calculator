# covenant-calculator
# Калькулятор ковенантов по договору ВКЛ № 12Р-К-2346/26

Онлайн-калькулятор финансовых ковенантов и отлагательных условий по договору об открытии
возобновляемой кредитной линии между АО «МСП Банк» и ООО «Амбрелла Альянс» от 19.08.2026.

**Открыть:** https://u-accounts.github.io/covenant-calculator/

## Что считает

Финансовые ковенанты (Приложение № 3 к Договору):

| Пункт | Ковенант | Норматив |
|---|---|---|
| 9 | Безубыточность деятельности | ≥ 0 |
| 10 | Снижение выручки к аналогичному периоду прошлого года | не ниже −15% |
| 13 | Отчуждение внеоборотных активов | ≤ 20% стр. 1100 |
| 14 | Долг / Операционная прибыль | от 0 до 3,0 |
| 15 | Чистые активы | ≥ 1 522 000 000 ₽ |
| 16 | Просроченная свыше 90 дней ДЗ | ≤ 25% ДЗ |
| 18 | CAGR выручки или сохранение численности | CAGR ≥ 12% (10% для МТК) |
| 21 | Дивиденды и распределение прибыли | ≤ 50% ЧП за 4 квартала |
| 24 | Чистые кредитовые обороты | ≥ 200 000 000 ₽ в квартал |
| 29 | Долг оборотный / Среднемесячная выручка | ≤ 3,0 |
| 30 | Ebit / Проценты к уплате | ≥ 1,5 |

Дополнительно:

- **Отлагательные условия по траншу** (раздел 8): свободный остаток лимита, п. 1.9, п. 2.5 (лимит 70% от Контракта), п. 2.7 (покрытие ≥ 1,4), порог 200 млн ₽.
- **Пороги согласования сделок** — пп. 11, 12, 17 (50 000 ₽ за 12 месяцев).
- **Расчет неустоек** — раздел 12 Договора.

У каждого показателя и каждого поля ввода есть кнопка **i**, раскрывающая дословный текст
соответствующего пункта Договора с определением показателя.

## Как пользоваться

1. Выбрать единицы ввода (рубли / тыс. / млн) — по умолчанию тыс. руб.
2. Внести значения строк бухгалтерского баланса и отчета о финансовых результатах.
3. Расчет обновляется на лету; статус каждого ковенанта — «Соблюдено», «Проверить», «Нарушено».
4. Кнопка «Печать / PDF» формирует версию для приложения к отчету перед Кредитором.
5. Кнопка «Пример данных» заполняет форму условными цифрами, чтобы посмотреть работу расчета.

Введенные значения хранятся только в локальном хранилище браузера (localStorage) на вашем
устройстве. Никакие данные никуда не передаются — страница полностью статическая, без сервера,
без внешних запросов и без аналитики.

## Публикация

Один файл `index.html`, без зависимостей и сборки. Раздается GitHub Pages из ветки `main`,
корневая папка. Чтобы обновить расчет — отредактировать `index.html` и запушить.

## Оговорка

Расчет носит справочный характер и воспроизводит формулы, прямо закрепленные в тексте Договора.
Показатели «Операционная прибыль» и «Ebit» по условиям Договора допускают исключение эффекта
курсовых разниц по валютным обязательствам со сроком погашения свыше срока кредита и разовых
(случайных) операций — такие корректировки вносятся вручную в соответствующие строки.
Порядок расчета чистых активов Договором не установлен и применяется по приказу Минфина России
от 28.08.2014 № 84н. Итоговое значение показателей определяет Кредитор.
